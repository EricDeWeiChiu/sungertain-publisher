# 三才靈芝農場 博客文章自動生成系統

**Sungertain Ganoderma Farm Blog Article Generator Skill**

一個為「三才靈芝農場」設計的自動化博客文章生成系統，能夠生成SEO優化、經過驗證、包含高質量參考資源的博客文章。

## 快速開始

### 使用此技能的基本步驟

1. **提供基本信息**：
   ```
   日期：YYYYMMDD (例如: 20260514)
   分類：選擇以下之一
   - 入門認識
   - 選購指南
   - 飲食指南
   - 保存方式
   - 常見問題
   - 深入認識
   
   推薦產品：從驗證清單中選擇
   任何特殊需求：(可選)
   ```

2. **技能將生成**：
   - 完整的Meta信息表格（SEO優化）
   - 600-1000字的文章主體
   - 5-7條經過驗證的參考資源
   - 格式化的Word文檔（.docx）

3. **輸出文件**：
   文件名格式：`YYYYMMDD_分類_產品名稱.docx`
   
   範例：`20260514_入門認識_靈芝黑木耳露.docx`

## 文章類別指南

### 入門認識 (Introduction)
- **目標受眾**：初次接觸靈芝或該產品的消費者
- **重點**：基本知識、安全性、基礎益處
- **結構**：什麼是靈芝 → 基本功效 → 安全性 → 入門建議

### 選購指南 (Buying Guide)
- **目標受眾**：正在考慮購買或對比不同產品
- **重點**：產品對比、選擇建議、價值判斷
- **結構**：產品類型對比 → 規格差異 → 選擇建議 → 價格分析

### 飲食指南 (Dietary Guide)
- **目標受眾**：已購買或想知道如何食用
- **重點**：食用方法、時間、搭配、用量
- **結構**：沖泡/食用方法 → 最佳時間 → 搭配建議 → 日常融入

### 保存方式 (Storage Guide)
- **目標受眾**：購買後需要妥善保存
- **重點**：儲存條件、環境、保質期、品質判斷
- **結構**：儲存要求 → 環境條件 → 保質期 → 品質檢查

### 常見問題 (FAQ)
- **目標受眾**：有具體疑問的消費者
- **重點**：解答常見問題、使用建議、禁忌
- **結構**：Q&A格式，涵蓋5-7個常見問題

### 深入認識 (Deep Knowledge)
- **目標受眾**：想深入了解科學原理的消費者
- **重點**：科學研究、成分分析、臨床證據
- **結構**：科學原理 → 成分分析 → 臨床研究 → 專家見解

## 參考資源準則

### 來源優先級

**1級（最優先）**：
- 學術期刊和同行評審研究
- 官方衛生部門（WHO、CDC、衛福部）
- 國家級認證研究機構
- 大學醫學院發布

**2級（推薦）**：
- 知名醫療和健康網站
- 認證營養師和專家
- 認可的專業組織
- 教科書和學術著作

**3級（可用）**：
- 信譽良好的新聞網站
- 行業專家部落格
- 品牌官方知識庫（針對產品信息）

### URL要求
- ✅ 具體文章/頁面URL
- ✅ 帶有article ID的研究頁面
- ❌ 首頁 (example.com, example.com/)
- ❌ 通用類別頁面 (example.com/news/)
- ❌ 沒有具體內容指向的域名

### EEAT說明示例

每個參考資源應包含EEAT說明，例如：

```
相關性說明：
- 專業性(Expertise)：來自認證營養師團隊
- 權威性(Authoritativeness)：WHO官方出版
- 真實性(Authenticity)：包含2023年臨床試驗數據
- 可信度(Trustworthiness)：透明的研究方法論和利益聲明
```

## 常見陷阱

### 警告 ⚠️

❌ **不要**：
- 編造或虛構產品名稱
- 使用首頁URL作為參考
- 製造虛假健康聲稱
- 提供醫療建議（應該說「諮詢專業人士」）
- 忽視參考資源的權威性
- 超過1000字或少於600字

✅ **應該**：
- 使用驗證清單中的產品
- 提供具體頁面URL
- 基於科學事實
- 使用謙虛措辭
- 優先選擇權威來源
- 在質量和數量間取得平衡
