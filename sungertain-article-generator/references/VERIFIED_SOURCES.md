# 已驗證參考資源指南

本文檔列出符合EEAT原則的已驗證參考資源，可直接用於文章撰寫。

## 1級來源 (最優先) - 學術與官方

### 醫學研究資料庫

#### PubMed Central (NIH)
- **URL模式**: https://pubmed.ncbi.nlm.nih.gov/[article-id]
- **EEAT強度**: ⭐⭐⭐⭐⭐ (最高)
- **用途**: 靈芝、菇類、免疫系統研究
- **優勢**: 同行評審、學術可信度高
- **驗證方式**: 搜索「ganoderma」或「reishi」+「clinical trial」

示例：
```
[1]. Ganoderma lucidum polysaccharides promote immune function - 
     NIH PubMed Central
     https://pubmed.ncbi.nlm.nih.gov/[article-id]
     存取日期：2026-05-14
     EEAT: 同行評審、臨床數據、官方醫學資料庫
```

#### Google Scholar
- **URL模式**: https://scholar.google.com/scholar?q=[query]
- **EEAT強度**: ⭐⭐⭐⭐ (高)
- **用途**: 學術論文索引和全文取得
- **優勢**: 廣泛涵蓋學術資源

## 搜索技巧

### 尋找優質參考資源的方法

1. **特定搜索詞**：
   - 「[產品名] + clinical trial」
   - 「[產品名] + peer reviewed」
   - 「[產品名] + systematic review」

2. **限定域名搜索**：
   ```
   site:pubmed.ncbi.nlm.nih.gov ganoderma
   site:scholar.google.com reishi immune
   site:fda.gov dietary supplement
   ```

3. **識別學術文章**：
   - URL包含「/pubmed/」或「/article/」
   - 標題包含「study」、「trial」、「research」
   - 有作者、發表日期、機構信息

### 避免的來源

❌ **不要使用**：
- Wikipedia (雖然可用於背景，但不作為主要參考)
- 個人部落格（無credentials）
- 社交媒體貼文
- 健康聲稱未經驗證的網站
- 已過時的信息（超過5年未更新）
- 明顯的商業網站（無第三方驗證）

## EEAT驗證清單

使用任何來源前，檢查：

### Expertise (專業性)
- [ ] 作者有相關credentials (MD, PhD, RD等)
- [ ] 來自學術或醫療機構
- [ ] 內容基於科學知識

### Authoritativeness (權威性)
- [ ] 是官方或認可的組織
- [ ] 在該領域獲得廣泛認可
- [ ] 有明確的編輯或審查流程

### Authenticity (真實性)
- [ ] 提供具體數據或研究
- [ ] 有完整的參考資料清單
- [ ] 不依賴主觀聲稱

### Trustworthiness (可信度)
- [ ] 透明的方法論
- [ ] 披露任何利益衝突
- [ ] 更新日期清晰可見
- [ ] 提供聯繫或反饋方式

## 常用EEAT說明範本

在撰寫文章時，使用以下格式說明參考資源的EEAT：

```
相關性說明：
- 專業性(Expertise): [誰撰寫/為什麼他們合格]
- 權威性(Authoritativeness): [機構或出版物的信譽]
- 真實性(Authenticity): [提供什麼類型的證據/數據]
- 可信度(Trustworthiness): [透明度和客觀性]
```

### 範例

```
[1]. Polysaccharides from Ganoderma lucidum Promote Th1/Th2 Cytokine 
     Balance in Mice - NIH PubMed Central
     https://pubmed.ncbi.nlm.nih.gov/[example-id]
     存取日期：2026-05-14
     
相關性說明：
- 專業性：國家衛生研究院的科學研究團隊
- 權威性：NIH官方資料庫，同行評審發表
- 真實性：包含具體的實驗數據和數據分析
- 可信度：透明的研究方法論，無商業偏見
```
