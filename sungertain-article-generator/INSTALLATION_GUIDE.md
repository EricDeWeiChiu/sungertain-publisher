## 🚀 安裝步驟

### 方式1：直接安裝Skill檔案（推薦）

1. **取得Skill檔案**：
   - 文件名：`sungertain-article-generator.skill`
   - 此為包含整個Skill目錄的zip檔案

2. **在Cowork中安裝**：
   - 開啟Cowork應用
   - 進入「設定」→「技能」
   - 點擊「安裝技能」
   - 選擇 `sungertain-article-generator.skill` 檔案
   - 點擊確認安裝

3. **驗證安裝**：
   - 在Cowork中搜索「sungertain」
   - 應該看到「三才靈芝農場 博客文章自動生成系統」

### 方式2：手動複製Skill目錄

1. **複製整個Skill目錄**：
   ```
   cp -r sungertain-article-generator ~/.[cowork-skills-path]/
   ```

2. **重新啟動Cowork**

3. **驗證技能出現在列表中**

## 🎯 快速開始

### 基本使用流程

1. **開啟Claude或Cowork**

2. **觸發此技能**（方式任選其一）：
   - 直接提及「三才靈芝農場」
   - 提及「靈芝博客」或「文章生成」
   - 明確輸入產品名稱和日期

3. **提供所需信息**：
   ```
   日期：20260514
   分類：入門認識
   推薦產品：靈芝黑木耳露 (瓶)
   ```

4. **技能執行**：
   - 生成Meta信息表格
   - 撰寫文章主體（600-1000字）
   - 編譯參考資源（5-7條）
   - 輸出Word文檔

5. **下載結果**：
   - 文件名：`YYYYMMDD_分類_產品.docx`
   - 準備發佈或進一步編輯

### 使用範例

**提示：**
```
根據我們的7日計劃，生成2026年5月14日的文章。
分類：入門認識
推薦產品：靈芝黑木耳露 (瓶)

請生成完整的Word文檔，包含Meta信息表格、600-1000字的文章、和5-7條驗證的參考資源。
```

## ⚙️ 故障排除

### 常見問題

#### 問題1：「技能未被識別」
**解決**：
- 確認Skill檔案正確安裝
- 重新啟動Cowork應用
- 檢查Cowork版本是否最新

#### 問題2：「產品不在清單中」
**解決**：
- 查看SKILL.md中的完整產品清單
- 使用正確的SKU（例：FD-WOODEAR-001）
- 更新產品清單（如有新產品）

#### 問題3：「參考資源URL無效」
**解決**：
- 使用VERIFIED_SOURCES.md中的預驗證來源
- 確保URL為具體頁面，非首頁
- 驗證URL仍然有效（最近檢查日期）

#### 問題4：「文章字數不符」
**解決**：
- 檢查實際字數（應為600-1000字）
- 如過短，添加更多細節
- 如過長，刪除冗餘內容

#### 問題5：「Meta標題/描述長度不符」
**解決**：
- SEO標題：應為40-60字元
- Meta描述：應為120-160字元
- 使用字數統計工具驗證

## 📚 進階主題

### 自訂產品清單

如要添加新產品或修改現有產品：

1. **編輯 SKILL.md**：
   ```markdown
   ### 新的產品系列
   | SKU | 產品名稱 | 價格 |
   |-----|--------|------|
   | NEW-001 | 新產品名稱 | $價格 |
   ```

2. **更新 evals.json**：
   - 添加新的測試用例
   - 包含產品驗證測試

3. **更新 article_generator.py**：
   - 修改 `PRODUCT_DATABASE` 字典

4. **測試**：
   - 運行評估以確保新產品有效

### 自訂輪轉計劃

如要修改7日輪轉：

1. **編輯 SKILL.md 中的「產品輪轉安排」**

2. **更新 article_generator.py 的 `ROTATION_PLAN`**

3. **更新 README.md 中的「7日輪轉計劃」表格**

4. **重新運行評估測試**

### 添加新分類

如要超越6個預定分類：

1. **評估影響**：
   - 調整7日輪轉計劃
   - 更新所有文檔

2. **建議**：
   - 先試驗新分類的手動版本
   - 驗證內容質量
   - 更新Skill文檔
