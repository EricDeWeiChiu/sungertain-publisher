## 🚀 快速參考

### 🔑 核心概念

```
靈芝文章審核系統 = AI自動審查 + 人工審核 + 決策流程
```

**兩道關卡：**
1. **AI自動審查**（規則引擎）→ 檢查規範違反
2. **人工審核**（編輯決策）→ 檢查內容品質 + 做出發布決策

**四種決策：**
- ✓ **通過** → 發布至官網
- ① **重新產文** → 重新生成內容
- ② **手動調整** → 編輯修改後重新審查
- ③ **刪除** → 放棄該選題

### ⏱️ 典型週期

| 場景 | 流程 | 週期 |
|------|------|------|
| 優質內容 | AI✓ → 審核✓ → 發布 | 2-3天 |
| 規範違反 | AI✗ → 審核②調整 → 審查✓ → 發布 | 3-4天 |
| 完全不符 | 審核① → AI重產 → 審查✓ → 發布 | 4-5天 |
| 廢棄選題 | 審核③刪除 | 1-2天 |

### 📊 成功指標

- AI審查通過率：≥80%
- 編輯審核通過率：≥90%
- 月產出量：20-30篇/月
- 平均週期：2-3天/篇

## 💡 最佳實踐

### 📌 編輯審核
1. **逐項檢查** - 完整檢查8個項目，不要跳過
2. **參考清單** - 每次都對照「檢查清單」做決策
3. **記錄簽名** - 在清單上簽名和日期

### 📌 內容經理
1. **定期監控** - 每週檢查通過率和指標
2. **及時優化** - 發現問題時快速更新AI Prompt
3. **團隊培訓** - 確保編輯正確理解標準

### 📌 技術負責人
1. **集成規則** - 將01_AI審查Prompt.md集成到系統
2. **自動化流程** - 根據04_流程圖.md設計工作流
3. **監控系統** - 跟蹤AI審查結果和通過率
